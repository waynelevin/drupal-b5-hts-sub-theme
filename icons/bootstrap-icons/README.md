# Bootstrap Icons

[Bootstrap Icons](https://icons.getbootstrap.com/) **1.13.2** (MIT licence,
see `LICENSE`), loaded on every page by the theme's `vsm/bootstrap-icons`
library (a dependency of `global-styling`).
Use them in content or templates as `<i class="bi bi-calendar-event"></i>`.

Files, copied unchanged from the `font` folder of the Bootstrap Icons
release:

- `bootstrap-icons.min.css` and `fonts/`: the icon font.
- `bootstrap-icons.json`: the icon names and their code points.

To update, download the new release from
https://github.com/twbs/icons/releases, replace these files with the ones
from its `font` folder (and `LICENSE`), and change the version above and in
`vsm.libraries.yml`.
